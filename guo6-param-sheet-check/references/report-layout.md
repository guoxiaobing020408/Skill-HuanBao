# 栏目位置与解析注意事项

解析失败或字段取不到时先看这里。

## 参数表结构

一张大表，五列：`段名 | 标签 | 值 | 标签 | 值`。段名在第一行出现，后续行该格为空（纵向合并的续格）。

分段依次为：整车参数、发动机参数、变速箱参数、底盘参数、污染物控制装置参数。

行内特例：

- 变速箱的「档位数」「速比」两行只有三格，是单值行。
- 「速比」在参数表里是一整串逗号分隔的数值。
- 表尾有两行说明文字，不属于表格。

## 报告结构（两份报告通用）

1. 封面与检验结论：只有报告编号、产品型号、生产企业，不是取数来源。
2. 「检验车辆基本参数」表：五列结构，和参数表一致，段名为整车参数、发动机、变速箱、底盘。这是发动机与变速箱字段的主来源。
3. 「污染控制装置」表：三列 `装置 | 型号 | 生产厂`，参数表要求写成 `型号/生产厂`。
4. 「检测用燃料」表（仅排放报告有）：三行 `柴油 | 润滑油 | 反应剂`，每行依次是生产厂、规格。

## 容易踩的坑

- 报告里的段名是「发动机」「变速箱」「底盘」，参数表里带「参数」二字，比对前统一去掉后缀。
- 报告里的「污染控制装置」在参数表叫「污染物控制装置参数」。
- 参数表栏目名和报告栏目名不完全一致：参数表「最大扭矩/转速」对应报告「最大净扭矩/转速」；参数表「发动机型号」对应报告「型号」；参数表「发动机编号」对应报告「编号」。
- 参数表里「反应剂控规格型号」多一个「控」字，是原表写法，规则表按原样写。
- 报告里的未安装写法是 `--`，参数表要求 `——`，写表前必须统一。
- 「中冷器」行在排放报告的污染控制装置表里只有型号没有厂家，取值时不能要求三格齐全。
- 纵向合并单元格的文字是竖排，读出来每字一行，比对前必须去掉换行。
- 两份报告的「发动机编号」不同属于正常现象（不同试验样车），该字段一律人工按实车打刻号填。
- 速比、档位数、主减速器速比以噪声报告为准；排放报告不作要求，即使数值不同也不取排放报告的。
- 「空气滤清器」「排气消声器」「排气管」「膨胀室」「进气消声器」只在噪声报告里出现；「喷油泵」「共轨管」「喷油器」「增压器」「中冷器」「EGR」「曲轴箱气体再循环装置」「EECU」「OBD」「DCU」「DPF控制单元」只在排放报告里出现。取错报告会得到空值。

## 底盘合格证 / 整车合格证看什么

合格证一般是照片或扫描件，没有表格结构，用读图逐项看。规则表「依据文件」列指向它们的字段，就照下表去对。

底盘合格证（或一致性证书）上能读到：

| 合格证栏目 | 对应参数表字段 |
|---|---|
| 底盘型号 / 底盘名称 / 底盘生产企业 | 底盘参数 › 型号、名称、生产厂 |
| 底盘类别（二类/三类） | 底盘参数 › 分类 |
| 最高设计车速 | 整车参数 › 最大设计车速(km/h) |
| 轮胎规格（如 7.00R16LT 8PR） | 整车参数 › 轮胎型号 |
| 轮胎数 | 整车参数 › 轮胎数量(个) |
| 驱动形式 | 整车参数 › 驱动方式 |
| 总质量 | 整车参数 › 最大总质量(kg) 的旁证 |
| 发动机型号 / 额定功率 / 排量 | 与两份报告互校 |

整车合格证 / 铭牌上能读到：车辆型号名称、生产厂、制造日期、外廓尺寸、整备质量（基准质量 = 整备质量 + 100）、驾驶室准乘人数、燃料种类。

对不上时的处理：合格证与参数表不一致，先怀疑参数表抄错（尤其外廓尺寸、整备质量、乘员数），列成「表内值 vs 合格证值」交用户定，不要自动改。底盘合格证上的整备质量是**底盘**的，不等于整车整备质量，别直接填进基准质量。
